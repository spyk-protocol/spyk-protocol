# Spyk Protocol - Solana Programs

This directory contains the Solana programs for Spyk Protocol.

## Programs

### noir-verifier

A Noir ZK proof verifier for OFAC compliance verification.

**Features:**
- Verifies Noir proofs generated by the smt_exclusion circuit
- Structural validation of 388-byte compressed proofs
- Supports both stateless verification and stored verification results
- Emits verification events for off-chain indexing

## Prerequisites

1. **Rust** (latest stable)
   ```bash
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   ```

2. **Solana CLI**
   ```bash
   sh -c "$(curl -sSfL https://release.anza.xyz/stable/install)"
   ```

3. **Anchor CLI** (v0.30.1)
   ```bash
   cargo install --git https://github.com/coral-xyz/anchor --tag v0.30.1 anchor-cli --locked
   ```

## Build

```bash
cd programs
anchor build
```

The compiled program will be at: `target/deploy/noir_verifier.so`

## Deploy

### Devnet

1. Configure Solana for devnet:
   ```bash
   solana config set --url devnet
   ```

2. Get some devnet SOL:
   ```bash
   solana airdrop 2
   ```

3. Deploy:
   ```bash
   anchor deploy --provider.cluster devnet
   ```

4. Note the deployed program ID and update `spyk-sdk/src/noir/verifier.ts`:
   ```typescript
   export const VERIFIER_DEFAULTS = {
     DEVNET_PROGRAM_ID: new PublicKey('<YOUR_DEPLOYED_PROGRAM_ID>'),
     // ...
   };
   ```

### Mainnet

For mainnet deployment, contact the Spyk Protocol team.

## Program Architecture

The verifier program uses Anchor framework and provides two instructions:

### `verify_proof`
Stateless verification - verifies the proof and emits an event.

```rust
pub fn verify_proof(
    ctx: Context<VerifyProof>,
    proof: [u8; 388],
    address: [u8; 32],
    root: [u8; 32],
) -> Result<()>
```

### `verify_and_store`
Stores verification result on-chain in a PDA account.

```rust
pub fn verify_and_store(
    ctx: Context<VerifyAndStore>,
    proof: [u8; 388],
    address: [u8; 32],
    root: [u8; 32],
) -> Result<()>
```

## Demo Mode

For demos without a deployed program, use the mock verifier:

```typescript
import { createMockNoirVerifier } from '@spyk-protocol/sdk/noir';

const verifier = createMockNoirVerifier();
const result = await verifier.verifyOnChain(proof);
```

The mock verifier performs the same structural validation as the on-chain program.
